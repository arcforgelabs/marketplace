# Explainer

Public copy of the Arc Forge explainer skill: visual explainer pages, diagrams first, every part opens a definition. Any agent can read it: start with [SKILL.md](SKILL.md).

- [references/chart-lab.html](references/chart-lab.html): every rated chart kind, drawn on one subject (example data).
- [examples/starter.html](examples/starter.html): copy it to start a page.
- [examples/explainer-kit.html](examples/explainer-kit.html): a full page that uses every renderer.

Generated by `scripts/export-public` in the private `arcforgelabs/tools` repo (`components/skills/explainer`; the plugin's PROVENANCE.json names the commit). The `scripts/` folder stays in the source repo. This public tree does not include it.

Theme values and logos are not stored in this folder. They come from `@arcforgelabs/themes` at `github:arcforgelabs/themes#v2026.10.1`. The tools mirror will retarget `scripts/sync-themes` to fetch that release.
